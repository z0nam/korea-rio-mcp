# jeju_domestic_leisure — 출처

내국인 국내 레저 관광객(축제·행사 방문)의 제주 체류 소비 단가.

- **단가(unit_cost.csv)**: 한국관광공사 「국민여행조사」 기반 1인당 항목별 지출액.
  제주연구원 새연교 분석보고서에서 인용한 월별(7~10월) 단가. 10월은 9월 값 동일 적용.
- **부문 매핑(industry_mapping.csv)**: 한국은행 2020 지역산업연관표 통합중분류(83부문).
  항공료·선박료는 부문코드 0 = 역외 발생으로 지역내 효과 0% 처리.
- **최초 사용**: 26p17 서귀포 축제 경제효과 분석 (`compute_assumptions.py`).
- **주의**: 여름·가을 평균 단가라 비수기 행사에 그대로 쓰면 10~20% 과대 가능
  (`meta.json`의 `default_weight`를 행사 시기에 맞게 오버라이드).
