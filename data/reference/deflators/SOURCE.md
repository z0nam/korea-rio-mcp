# 부문별 산출 디플레이터 (중분류 83부문, 2020=1.0)

`sector_deflators.csv` 는 한국은행 지역산업연관표 2020 중분류 83부문 각각에
2020〜2025년 연간 산출 디플레이터를 붙인 표다. 2020년 불변가격 계수(취업유발계수 등)를
당해년 명목 지출에 적용할 때 지출을 2020년 가격으로 환산하는 데 쓴다(#20).

## 열

| 열 | 뜻 |
|---|---|
| `sector_code`, `sector_name` | 중분류 83부문 코드·이름 (`src/rio_mcp/data/coefficients/induce_coef_제주_2020_중분류.csv` 와 같음) |
| `year` | 2020〜2025 |
| `deflator` | 원계열 ÷ 같은 계열의 2020년 값, 소수 6자리 반올림. 2020 = 1.000000 |
| `source_table`, `source_item` | ECOS 통계표 코드·항목 코드 |
| `grade` | 대응 품질 (아래) |

## 원자료 (ECOS, 확인일 2026-11-20)

| 표 | 이름 | 단위 | 쓴 항목 |
|---|---|---|---|
| `405Y007` | 4.1.3. 총산출물가지수 (연간) | 2020=100 | `1A` `2A` `301A`〜`313A` `401A` `402A` `501A`〜`510A`, 총지수 `*A` |
| `200Y111` | 경제활동별 GDP 디플레이터 (연간) | 2020=100 | `1106` 도소매 및 숙박음식업, `1110` 공공행정·국방 및 사회보장, `1112` 의료·보건업 및 사회복지서비스업 |
| `200Y112` | 국내총생산에 대한 지출 디플레이터 (연간) | 2020=100 | `1020111` 건설투자 |

`raw/` 에 항목별 ECOS `StatisticSearch` 응답 원문(JSON, 키 정렬·들여쓰기만 함)이 있다.
응답에는 인증키가 들어 있지 않다. 2026-11-20 에 공개 `sample` 키로 받은 값이
사용자 인증키로 받은 값과 32개 항목 × 6개 연도 모두 일치함을 확인했다.

## 작성 방법

```
python scripts/build_deflators.py           # raw/ → sector_deflators.csv (오프라인)
python scripts/build_deflators.py --fetch   # ECOS에서 raw/ 갱신 후 다시 생성
```

- 83부문 → ECOS 항목 대응은 스크립트의 `MAPPING` 이 원본이다.
- 수치 변형은 `round(값 / 2020년 값, 6)` 하나뿐이다. 보간·평활·가중 합성은 하지 않는다.
- `--fetch` 는 `ECOS_API_KEY` 환경변수가 있으면 그 키를, 없으면 공개 `sample` 키를 쓴다.
  키는 요청 URL에 들어가므로 URL을 출력하지 않는다. 연간 6행이라 sample 키의 10행 제한에 걸리지 않으며,
  행 수가 6이 아니면 중단한다.
- `tests/test_deflators.py` 가 `raw/` → CSV 재현 일치를 검사한다.

## VA대리 근거와 한계

산출 지수가 없는 부문에 부가가치 디플레이터를 대리로 쓰는 것은 OECD ICIO 작성 선례를
근거로 했다(#20 검토). 산출과 부가가치 디플레이터는 중간투입 가격 변화만큼 갈라질 수 있으므로,
두 지수가 모두 있는 부문에서 격차를 재 ±10% 를 허용 기준으로 삼았다.

2021〜2025년 중 최대 |VA 디플레이터 ÷ 산출 디플레이터 − 1|:

| 부문 (VA 항목 vs 산출 항목) | 최대 격차 |
|---|---|
| 기타서비스 (`1113` vs `510A`) | 0.7% |
| 교육 (`1111` vs `508A`) | 1.2% |
| 음식점·숙박 (`1106` vs `502A`) | 3.0% |
| 부동산 (`1109` vs `505A`) | 3.2% |
| 정보통신 (`1114` vs `503A`) | 3.6% |
| 사업지원 (`1115` vs `507A`) | 7.0% |
| 전문·과학·기술 (`1115` vs `506A`) | 7.6% |
| 예술·스포츠·여가 (`1113` vs `509A`) | 9.9% |
| 건설 (`1105` vs `200Y112` `1020111` 건설투자) | 6.0% |
| **±10% 초과** 운송 (`1107` vs `501A`) | 12.3% |
| **±10% 초과** 금융·보험 (`1108` vs `504A`) | 14.9% |
| **±10% 초과** 제조 (`1103` vs `3A`) | 16.5% |

- 서비스업 대부분은 ±10% 안에 든다. VA대리를 쓰는 4개 부문(도소매·공공행정·의료·복지)은
  격차를 직접 잴 산출 지수가 없으므로, 이 표는 서비스업 일반의 경향으로만 참고한다.
- ±10% 를 넘는 운송·금융·제조는 총산출물가지수가 있으므로 VA대리를 쓰지 않는다.
- 52 도소매의 대리 항목 `1106` 은 숙박음식업과 합쳐진 계열이다. 도소매만의 산출 디플레이터는 ECOS에 없다.
